# ATRI喵 · 个人主页

一个手写的静态个人网站：卡片式首页 + 5 个子页面 + 3 个专业小工具。
纯 HTML / CSS / JavaScript，不依赖任何框架和构建工具，双击 `index.html` 就能打开。

## 目录结构

```
.
├─ index.html              首页（卡片仪表盘）
├─ blog.html               个人介绍
├─ projects.html           我的项目（含 3 个小工具的入口）
├─ about.html              关于网站
├─ share.html              推荐网址
├─ bloggers.html           优质资源
├─ tools\
│  ├─ tolerance.html       尺寸公差与配合计算器
│  ├─ gear.html            齿轮传动参数计算器
│  └─ material.html        材料理论重量计算器
└─ assets\
   ├─ css\style.css        全部样式
   ├─ js\data.js           站点内容（文字、链接、列表都在这里）
   ├─ js\main.js           渲染与交互（时钟、日历、音乐、主题切换）
   ├─ audio\               背景音乐
   └─ images\
      ├─ avatar.svg        头像
      └─ backgrounds\      背景图
```

## 页面说明

- **首页**：左上个人卡（可点头像回首页）、最新文章、贴纸装饰、问候语、社交按钮；
  右列是写文章按钮、数字时钟、日历、音乐播放器和点赞。
- **子页面**：左侧导航卡 + 右侧内容列表，导航项会自动高亮当前页。
- **主题**：右上角按钮切换浅色 / 暗色，选择记在浏览器里。

## 改内容

内容全部集中在 **`assets/js/data.js`**：个人资料、导航、各页面标题、问候语、社交链接、
音乐、关于页正文、文章列表、项目列表、推荐网址、优质资源。

想加一条内容，照着已有条目的格式复制一段改就行。

## 改外观

**`assets/css/style.css`** 顶部的两个变量区：

- **背景**：`--bg-image` 里的图片路径、`--bg-scrim` 的遮罩浓度（数值越大，背景图越淡、文字越清楚）
- **主题色**：`--accent` 是主色，`--card-bg`、`--radius-card` 等控制卡片外观

## 三个小工具

都在 `tools\` 下，独立单文件，双击就能用，不联网：

| 工具 | 用途 |
| --- | --- |
| `tolerance.html` | 按 GB/T 1800.1（ISO 286-1）标准公差数值表，算标准公差值、写 `φ50H7(+0.025/0)` 这样的标注，并可判断 H/h 基准制配合的间隙/过盈 |
| `gear.html` | 标准直齿外啮合圆柱齿轮：分度圆、齿顶圆、齿根圆、基圆、中心距、传动比、圆周速度 |
| `material.html` | 圆钢/方钢/钢板/圆管/六角棒按材料密度算每米和每件理论重量 |
